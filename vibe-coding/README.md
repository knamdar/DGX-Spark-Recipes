# Vibe Coding

Vibe coding is already discussed in the [Spark official cookbooks](https://build.nvidia.com/spark/vibe-coding/instructions).

Nonetheless, I suggest two major improvements to enhance the vibe coding experience:

## a) Install Roo via VS Code Extensions

Through VS Code extensions, look for **Roo** and install it. Roo is an AI-powered coding assistant that integrates seamlessly with VS Code to provide an improved development experience.

## b) Login to WebUI and Retrieve qwen3-coder-next

Login to your WebUI and retrieve `qwen3-coder-next`. You will have a next-level experience of vibe coding with local LLMs.

This setup allows you to leverage powerful local language models for coding tasks while maintaining the flexibility and control of your DGX Spark environment.
